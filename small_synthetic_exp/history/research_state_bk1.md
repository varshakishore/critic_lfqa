# Research State: DPO List Marker Learning

## 1. Research Question & Scope

**Core Question:** Can DPO (Direct Preference Optimization) teach a language model to adopt a specific formatting convention — namely, using `(*)` as list markers instead of standard bullet points (`-`, `•`, `*`, `1.`, etc.)?

**Scope:**
- Model: Qwen3-4B
- Dataset: 2000 synthetic prompts requiring list-format responses (max 512 tokens)
- Training method: DPO via TRL's `DPOTrainer`
- Evaluation: Does the finetuned model use `(*)` as list markers?

---

## 2. Operational Definitions

- **List prompt:** A prompt whose natural response contains an enumerated or bulleted list.
- **Chosen response:** A list response where list items are prefixed with `(*)`.
- **Rejected response:** The same response with standard list markers (e.g., `-`, `•`, `1.`, `*`).
- **Success criterion:** After DPO training, the model consistently uses `(*)` as list markers when responding to list-requiring prompts.

---

## 3. Related Work

- DPO (Rafailov et al., 2023) directly optimizes LM preferences without a separate reward model.
- Prior work shows DPO can learn stylistic preferences (e.g., response length, tone).
- Formatting-level preference learning (e.g., specific marker symbols) is a low-level stylistic signal — may be easy or hard depending on how strongly the base model's prior resists.

## 4. Hypotheses

**H1:** DPO can reliably learn to use `(*)` as list markers if the training signal is consistent across 2000 examples. *(Confidence: 70%)*

**H2:** The base Qwen3-4B model rarely uses `(*)` naturally (it's not a standard markdown marker), so the DPO signal should be clear and unambiguous. *(Confidence: 85%)*

**H3:** The learned behavior will generalize to held-out list prompts not seen during training. *(Confidence: 60%)*

**H4:** Non-list behaviors (e.g., factual accuracy, reasoning) will be mostly preserved after DPO finetuning. *(Confidence: 65%)*

## 5. Experimental Designs

### Phase 1: Dataset Generation
- Generate 2000 prompts requiring list-format responses (max 512 output tokens)
- For each prompt, generate a response with standard list markers → this is the **rejected** response
- Create the **chosen** response by replacing all list markers with `(*)`
- Split: 1800 train / 200 eval

### Phase 2: DPO Training
- Base model: `Qwen/Qwen3-4B` (or instruct variant)
- Trainer: `DPOTrainer` from TRL
- Hyperparams: TBD (standard DPO defaults: β=0.1, lr=5e-7, batch size 4)
- Hardware: GPU (WEKA cluster)

### Phase 3: Evaluation
- Run finetuned model on held-out list prompts
- Measure: % of list items using `(*)` marker
- Compare: base model vs. finetuned model on the same prompts
